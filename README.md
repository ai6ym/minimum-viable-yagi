# Minimum Viable Yagi

3D printable parts for building tape measure yagi antennas.

Recently redesigned in OpenSCAD as parametric parts. Released as a kit on my website.

## Build Instructions

For the size of pipe and tape you have print one driven element block and two parasitic element blocks.

Cut two 17 3/4" tape measurements for the driven element, one 35 1/8" director element, and one 41 3/8" reflector element.

Find, borrow, purchase, or steal ten #6 3/8" wood screws, two six inch zip ties, one coax pigtail with your desired connector (pro-tip: make pigtails by cutting commercial cables in half and stripping the ends), one 4 1/2" wire (the match element - solid copper is best, around 20AWG / 0.5mm2), and four #6 ring terminals.

Crimp ring terminals on each end of the match element. Sand the charp edges of the cut elements and a bare metal patch for electrical contacts on one end of each driven element half (on the convex side). Touch up the sharp cut edges with enamel paint.

From that point follow the build instructions for the [kits on my store](https://store.ai6ym.radio/products/minimum-viable-yagi).
